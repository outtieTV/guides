# AzerothCore WotLK Glyph Vendors

This document contains the complete SQL script to add class glyph vendors to your AzerothCore WotLK server, along with the GM `.npc add` spawn commands for easy in-game placement.

---

## GM Spawn Commands

If you prefer to spawn the vendors manually in-game rather than using the hardcoded creature coordinates from the SQL, use the following commands:

* Deathknight → `.npc add 90500`
* Druid → `.npc add 90501`
* Hunter → `.npc add 90502`
* Mage → `.npc add 90503`
* Paladin → `.npc add 90504`
* Priest → `.npc add 90505`
* Rogue → `.npc add 90506`
* Shaman → `.npc add 90507`
* Warlock → `.npc add 90508`
* Warrior → `.npc add 90509`
